# Vision Architecture Exploration with `raxpy`

This repository contains the experimental setup and evaluation code for comparing convolutional (ResNet-34) and transformer (ViT-Small) vision backbones using space-filling design of experiments via `raxpy`.

## Overview

We benchmark two vision architectures with matched parameter scales (~21.3M parameters each) on image classification under varied optimization and data augmentation regimes:
- ResNet-34: Standard 34-layer residual network adapted for single-channel inputs, exploring stem convolution kernel size and dropout rate.
- ViT-Small: 12-layer vision transformer (embed dim 384, 6 heads, MLP dim 1536) adapted for small-format image classification, exploring patch size and dropout rate.

The experimental design leverages `raxpy`'s type-directed introspection to manage:
1. Branching factors: `Union[ResNetConfig, ViTConfig]` selecting mutually exclusive architecture sub-spaces.
2. Optional / Nullable factors: `Optional[AugmentationConfig]` enabling or bypassing random affine and crop augmentations.
3. Hierarchical configurations: Structured dataclasses encapsulating component-specific hyper-parameters.

## Requirements

The experiments require Python 3.9+ and the following libraries:
- `raxpy >= 0.3.0`
- `torch >= 2.0.0`
- `torchvision >= 0.15.0`
- `numpy`
- `scipy`

Install dependencies via:
```bash
pip install torch torchvision numpy scipy
pip install raxpy
```

## Running the Experiment

Use:
```bash
python -m experiment.run_experiment --n_points 20 --train_subset 3000 --val_subset 500 --epochs 1
```

### Command-line Arguments

| Argument | Default | Description |
| :--- | :--- | :--- |
| `--n_points` | `20` | Total design points generated by the space-filling designer |
| `--train_subset` | `3000` | Number of training samples drawn from MNIST |
| `--val_subset` | `500` | Number of validation samples drawn from MNIST |
| `--epochs` | `1` | Training epochs per experimental trial |
| `--seed` | `42` | Random seed for design generation and data subsampling |
| `--data_dir` | `./data` | Directory where MNIST dataset files are stored |
| `--output_dir` | `./experiment` | Directory to save evaluation logs and metrics |

## Results

Execution outputs are saved to:
- `experiment/results.json`: Detailed dictionary of all design points and measured performance metrics.
- `experiment/results.csv`: Tabular export containing architecture parameters, augmentation status, loss, accuracy, and runtime.
